# Biblia site

Marketing + privacy + support pages for the Biblia iOS app.

Deploy as GitHub Pages — same pattern as `Carekeep-site`, `AfterAction-site`, etc.

## Files

- `index.html` — marketing landing page
- `privacy.html` — privacy policy (required for App Store submission)
- `support.html` — support page (required for App Store submission)
- `styles.css` — shared parchment-palette styles

## Required App Store URLs

When filling out the ASC app record:

- Privacy Policy URL: `https://anulfito1991-wq.github.io/Biblia-site/privacy.html`
- Support URL: `https://anulfito1991-wq.github.io/Biblia-site/support.html`
- Marketing URL: `https://anulfito1991-wq.github.io/Biblia-site/`

## To publish

1. Create a public repo `anulfito1991-wq/Biblia-site`
2. Push this folder to it
3. Settings → Pages → Source: deploy from branch `main` / `(root)`
4. Wait ~30 seconds for Pages to publish
5. Verify the three URLs above resolve before submitting to App Review

## Style notes

Palette + typography mirror the app:
- Background: `#f5e8d1` (parchment)
- Ink: `#0f0a06` (deepened ink)
- Accent: `#b37330` (burnished amber)
- Body type: `ui-serif` / Source Serif fallback
- Chrome type: SF
